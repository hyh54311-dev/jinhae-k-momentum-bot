# 백테스트 (원고 수치 재현용)

책에 나오는 수익률과 낙폭이 어디서 나왔는지 누구나 다시 돌려 볼 수 있도록 정리한 폴더입니다. 실제 매매 코드(`kis_bot_multi.py`)와는 독립적이며, 이 폴더를 지워도 봇은 그대로 동작합니다.

## 실행 방법
```bash
python backtest/fetch_data.py   # 야후 파이낸스에서 가격 내려받기 (backtest/data/, 저장소에는 올리지 않음)
python backtest/backtest.py     # 결과 표 출력 + backtest/RESULTS.md 저장
```
파이썬 3.10 이상, 표준 라이브러리만 사용합니다. 야후 데이터는 내려받는 시점에 따라 마지막 달(미완성 월)과 수정주가가 조금 달라질 수 있어, 다시 돌리면 소수점 첫째 자리 정도 차이가 날 수 있습니다.

## 무엇을 계산하나
| 항목 | 내용 |
|---|---|
| 전략 | 4자산 동일비중, 올웨더형, K-듀얼모멘텀(봇 로직), 상위 2개 분산, 동일비중+AMS 필터, 코스피 보유, S&P500 보유 |
| 기간 | 최장(약 21년) / 최근 20년 / 최근 10년 / 전반부 / 후반부 |
| 지표 | 연평균, 최대 낙폭, 최악 12개월, 변동성, 월 회전율, 월 50만 원 적립 최종 자산 |
| 추가 | 위기 구간 낙폭, 연도별 수익률, 리밸런싱 방식 비교, 일부 자산이 약해질 때의 스트레스, 연금저축 대 일반계좌 세금 비교, 달러 기준 장기 비교 |

## 가정과 한계 (결과를 읽기 전에)
- 월말 종가 기준이며 마지막 달은 데이터 마지막 날까지의 미완성 월입니다.
- 연금계좌라서 매매세금이 없다고 보고, ETF 매매비용은 편도 0.05%를 모든 전략에 똑같이 적용했습니다.
- 실제 국내 ETF 대신 대용 자료를 씁니다: 코스피 지수(가격지수라 배당이 빠져 연 1.5%p 정도 낮게 계산), SPY, TLT, SHY, IEF, 금 선물, 원/달러 환산. 실제 ETF와는 총보수, 환 처리, 운용 방식 때문에 차이가 납니다.
- 모멘텀은 실제 봇과 같은 방식입니다. 전월 말 확정 종가로 신호를 내고 당월 말에 체결합니다.
- 세금 비교는 해외·금·채권 ETF 매매차익과 분배금 15.4%, 코스피 ETF 매매차익 비과세, 연금 수령 5.5%, 일시금 16.5%를 가정합니다. 금융소득종합과세와 개인별 세율은 반영하지 않았습니다.
- 과거 한 번의 경로일 뿐이며 미래 수익을 보장하지 않습니다.
